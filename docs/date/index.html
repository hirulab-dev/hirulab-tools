1949年〜2099年に対応
その年の規則で計算します。祝日は何度も法律が変わっているので、いまの規則を昔の年に当てると違う日が出ます。 成人の日は1999年まで1月15日、天皇誕生日は平成のあいだ12月23日、海の日は1995年まで無く、 体育の日は1999年まで10月10日でした。2020・2021年は五輪で海の日・山の日・スポーツの日が動いています。 振替休日は1973年4月12日から、国民の休日は1986年から。一日限りの休日(即位の礼など)も6つ入れてあります。 ここは期間タブの「営業日」の数にも効きます。

道具箱のトップ ・ 実験ログ（note） ・ X ・ ソース

祝日は現行(2026年時点)の国民の祝日に関する法律にもとづいて計算しています。過去の年について当時の法律との差が出る場合があります(ハッピーマンデー導入前、天皇誕生日の移動、オリンピック特措法による移動など)。 春分・秋分の日は 1980〜2099 年で有効な近似式によるもので、公式には前年2月の官報で確定します。重要な予定は必ず公式の暦で確認してください。
