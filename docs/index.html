正規表現テスタ

正規表現をその場で試して、パターンの意味を日本語で解説します。「この記号なんだっけ」を毎回ググらなくて済むように作りました。

文字数カウンタ

貼るだけで文字数・行数・段落数。X（旧Twitter）の重み付きカウント、原稿用紙換算、読了時間の目安まで一度に出します。

コントラスト比チェッカー

文字色と背景色のコントラスト比を WCAG 2.1 の AA / AAA で判定。色覚特性のシミュレーションと、基準を満たす色の自動提案つき。

日付計算機

期間・営業日・満年齢・学年・和暦をまとめて計算します。日本の祝日（春分秋分の計算、振替休日、国民の休日）に自動対応。

画像リサイズ・圧縮

画像を軽くしてサイズを変えます。よくある圧縮サイトと違い、画像はどこにもアップロードされません。読み込んだあとは機内モードでも動きます。
