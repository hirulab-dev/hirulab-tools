正規表現の置換プレビュー

正規表現の置換を、置き換える前に見せる道具です。 置換テンプレートに書いた $1 や $& を1つずつ読み下し、 置換後のどの文字がどこから来たかを対応づけて表示します。 JavaScript の置換にはエラーにならずに黙って別物になる書き方がいくつもあります。 そこを名指しするのがこの道具の目的です。

このページは通信を一切行いません。 解析も置換もすべてブラウザの中でやっています。読み込んだあとは機内モードでも動きます。 入力した正規表現や文字列がどこかに送られることはありません。

    自己検査
    
    
    
  
    

  
    
    JavaScript の置換で、エラーにならずに別物になるところ
    
      
      
    • $1 に対応するグループが無いと、エラーにならず $1 という文字がそのまま出ます。
        グループを1つ減らしたときに気づかないのはこれです。
      • 
      
    • $<名前> は、式に名前つきグループが1つでもあれば特別扱いされます。
        そのうえで名前の綴りが違うと、エラーにならず空文字になります（黙って消えます）。
        名前つきグループが1つも無い式なら、逆に $<名前> がそのまま文字として出ます。
      • 
      
    • \1 は後方参照ではありません。JavaScript の置換文字列ではただの 1です
        （\ は文字列リテラルの段階で消えます）。sed や Python の癖で書くとここで外れます。
      • 
      
    • ${1} も特別扱いされません。そのまま ${1} と出ます。
      • 
      
    • $` と $' はマッチの前・後ろを指しますが、
        どちらも「元の文字列」を指します。置換しかけの文字列ではありません。
      • 
      
    • g が無ければ最初の1件しか置き換わりません。エラーは出ません。
      • 
      
    • 長さ0のマッチ（x* など）は文字と文字の間に入ります。
        "abc".replace(/x*/g, "-") は -a-b-c- になります。
      • 
    
    
  
    

  
    
    この道具の作りと、確かめ方
    
      
      
    • 正規表現の解析器は鉄道図の道具・なぜマッチしないか診断と同じものです。
        3ページで1バイトも違わないことを、公開のたびに機械で照合しています。
      • 
      
    • 置換テンプレートの展開は自前で書いています。
        ブラウザの String.prototype.replace は結果の文字列しか返さないので、
        「どの文字がどのトークンから来たか」を出すには自分で組み立てるしかありません。
      • 
      
    • 自前である以上ずれる可能性があります。だから毎回その場でブラウザの
        replace と突き合わせ、結果を自己検査の欄に出しています。
        食い違ったらブラウザのほうが正しいと表示します。
      • 
      
    • 組み込みの検査ケースも同時に回しています。いま画面に出している入力もその中に入ります。
