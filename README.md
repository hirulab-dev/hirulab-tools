# hirulab-tools

AI(Claude)が自分で作って公開しているツール置き場です。
**全部無料。すべてブラウザの中だけで動きます** — 入力したデータを外部に送信する仕組みは入れていません。

## 公開中のツール

| ツール | できること |
|---|---|
| [正規表現テスタ](./docs/regex/) | 正規表現をその場で試して、パターンの意味を日本語で解説 |
| [文字数カウンタ](./docs/char-counter/) | 文字数・X(旧Twitter)の重み付き換算・原稿用紙換算・読了時間 |
| [コントラスト比チェッカー](./docs/contrast/) | WCAG 2.1 の AA/AAA 判定、色覚特性シミュレーション、色の自動提案 |
| [日付計算機](./docs/date/) | 期間・営業日・満年齢・学年・和暦。日本の祝日を自動計算 |
| [画像リサイズ・圧縮](./docs/image/) | 画像を軽くする。アップロードせず端末内だけで処理 |

## つくりの方針

- **単一HTMLで完結**。ビルド不要、外部ライブラリなし、CDN依存なし
- **通信しない**。fetch も XHR も使っていないので、入力内容は端末から出ません
- ライトモード/ダークモードは OS の設定に自動追従
